# 1C

📘 **Учебник «1С 8.3 — как создавать отчёты»**: простыми словами, для пятого класса.
Как создать отчёт **в Конфигураторе** и как пользоваться отчётом **в пользовательском режиме** — пошагово, со скриншотами, заданиями и словариком.

![Build and Deploy](https://github.com/vetan2022-svg/1C/actions/workflows/build.yml/badge.svg)

## 📖 Где посмотреть

- **Сайт-учебник (GitHub Pages):** https://vetan2022-svg.github.io/1C/
  > Сайт оживёт после однократного включения Pages: **Settings → Pages → Source → GitHub Actions** (это делает владелец репозитория, один раз).
- **Исходник страницы:** [`index.html`](index.html)

## 🗂 Структура

| Путь | Что это |
|---|---|
| `index.html` | Сам учебник — одна HTML-страница, без зависимостей |
| `assets/img/` | Скриншоты-иллюстрации к шагам |
| `tools/build.sh` | Скрипт сборки: проверяет ссылки на картинки, собирает `dist/` |
| `.github/workflows/build.yml` | GitHub Actions: сборка при каждом push + деплой на Pages |

## ⚙️ Сборка

Каждый **push** в `main` или в `arena/**` запускает GitHub Actions:

1. **Проверка** — все ли картинки из `index.html` на месте;
2. **Сборка** — готовый сайт кладётся в `dist/` и публикуется артефактом `site-dist`;
3. **Деплой** — если GitHub Pages включён, сайт публикуется на `vetan2022-svg.github.io/1C/`.

Запуск вручную: **Actions → Build and Deploy → Run workflow**.

## 🎯 Чему учит учебник

1. Что такое отчёт (таблица, диаграмма, итоги);
2. Два режима 1С: Конфигуратор vs 1С:Предприятие;
3. Создание отчёта **в Конфигураторе**: дерево объектов → форма → СКД → «Сформировать»;
4. Работа с отчётом **в пользовательском режиме**: мастер отчёта, отборы, период, диаграмма, печать и сохранение;
5. Три вида отчётов: встроенный, внешний (`.epf`), отчёт на СКД;
6. Задания, мини-тест и словарик.
